# backlog v0.1.2
## What changed
Ticket files stay formatter-clean (Prettier's Markdown rules). The ticket template in `SKILL.md` has a blank line after the front matter and no aligned comments. `set-status` now writes the ticket with no trailing spaces in the front matter, one blank line after it and one newline at the end.
## Why
Tickets written from the template or by `set-status` failed `prettier --check` in projects that format Markdown.
## Apply to your copy
1. In `tickets.ts`, add above `function git(`:
   ```ts
   export function tidy(text: string): string {
     const eol = text.includes("\r\n") ? "\r\n" : "\n";
     const lines = text.split("\n").map((l) => l.replace(/\r$/, ""));
     const close = lines.indexOf("---", 1);
     if (lines[0] !== "---" || close < 0) return text;
     const fm = lines.slice(0, close + 1).map((l) => l.trimEnd());
     const body = lines.slice(close + 1).join("\n").replace(/^\s*\n/, "").trimEnd();
     return [...fm, ...(body ? ["", ...body.split("\n")] : [])].join(eol) + eol;
   }
   ```
2. In `setStatus`, change `writeFileSync(path, res.text);` to `writeFileSync(path, tidy(res.text));`.
3. In your `SKILL.md`, put a blank line after the closing `---` of the template and after each heading, and write comments after a value with one space before the `#`.
4. Format the existing tickets once with your formatter.
## Check
Run `set-status` on a ticket, then your formatter check on `backlog/`. It reports nothing for that file.
