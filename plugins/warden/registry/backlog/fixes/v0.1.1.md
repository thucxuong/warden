# backlog v0.1.1
## What changed
`tickets.ts` no longer uses `console.log` or `console.error`. Output goes through two small helpers, `writeOut` (stdout) and `writeErr` (stderr). Output and exit codes are the same.
## Why
Projects that lint `.claude/` with `no-console` failed every check on the copied script.
## Apply to your copy
1. Below the imports of `tickets.ts`, add:
   ```ts
   const writeOut = (s: string): void => void process.stdout.write(s + "\n");
   const writeErr = (s: string): void => void process.stderr.write(s + "\n");
   ```
2. Replace every `console.log(` with `writeOut(` and every `console.error(` with `writeErr(`.
3. If a local variable named `writeOut` or `writeErr` exists in your changes, rename it.
## Check
`grep -n "console\." .claude/skills/backlog/bin/tickets.ts` prints nothing, and the tool still prints the same output as before.
