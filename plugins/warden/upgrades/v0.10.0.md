Project tools can now own raw commands, and warden logs what the agent runs so the retro can suggest new tools.

1. Run `warden tools --init`. It writes `.warden/tools/replaces.json` as `{}` and keeps every file that exists. With `{}`, nothing is refused.

To make a tool the only way to do a job, list the raw commands it owns in `replaces.json` with `/warden:tools` (section "Replaced commands"), when the user asks for it.
