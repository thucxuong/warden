Warden logs what the agent runs so the retro can suggest new tools, a project tools skill tells the agent which tools exist, and `warden tools --verify tickets` checks the ticket tool.

1. Run `warden tools --init`. It writes `.warden/tools/replaces.json` as `{}` and keeps every file that exists.
2. Run `warden tools --skill`. It writes `.claude/skills/project-tools/SKILL.md`, the list of this project's tools for the agent.
3. Run `warden tools --verify tickets`. It tests the ticket tool in a throwaway worktree and changes nothing. If a row is `FAIL`, tell the user what it says; fix the tool only when the user agrees.

To list the raw commands a tool covers, so the skill and the retro can steer the agent to the tool, see `/warden:tools` (section "Raw commands a tool covers").
