Project tools can now own raw commands, warden logs what the agent runs so the retro can suggest new tools, and `warden tools --verify tickets` checks the ticket tool.

1. Run `warden tools --init`. It writes `.warden/tools/replaces.json` as `{}` and keeps every file that exists. With `{}`, nothing is refused.
2. Run `warden tools --verify tickets`. It only reads. If a row is `FAIL`, tell the user what it says; fix the tool only when the user agrees.

To make a tool the only way to do a job, list the raw commands it owns in `replaces.json` with `/warden:tools` (section "Replaced commands"), when the user asks for it.
