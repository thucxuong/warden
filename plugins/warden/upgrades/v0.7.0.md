No layout changes.

Optional: a project ticket tool may now print the statuses `backlog` (parked, never started) and `archived` (closed without doing). Add them to the tool's status list (and its `set-status` usage) when your ticket system has such states. A tool that prints only `todo`, `doing`, `review` and `done` keeps working.

Before the tool prints `backlog` or `archived`, make sure every teammate runs warden 0.7.0 or later: older versions reject those statuses.
