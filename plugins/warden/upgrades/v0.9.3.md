A ticket is set to done only once its task is merged, in the main checkout, never on the ticket branch.

1. If `.warden/steps.json` (`agent.ship`) or a how-to says the ticket status is committed on the ticket branch before the merge, change it to: warden sets the ticket to done after the merge.
2. Run `warden status`. For each live run at its ship step, run `git -C <its worktree> status --porcelain`. If the run's ticket file (for a file tool, `backlog/<id>.md`) shows as changed, the old ship prep set it to done there: run `git -C <its worktree> checkout -- <that file>`. Then run `warden next <id>`.
