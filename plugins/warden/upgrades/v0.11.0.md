A run in its own worktree now starts from the branch the main checkout is on, and ships back to it. The layout of `.warden/` does not change.

1. Read `.warden/tools/roles.json`. The pull request tool is the value of `pr` there, or `pr` when that key is missing. If `.warden/tools/` has no tool of that name, stop here: there is nothing to change.
2. Run that tool's `create` usage text, or read its code. If `create` already takes `--base <branch>`, stop here.
3. Add `--base <branch>` to `create`: it opens the pull request against that branch, and against `mainBranch` from `.warden/steps.json` when the option is left out. Without it, a run on another base opens its pull request against the main branch.
